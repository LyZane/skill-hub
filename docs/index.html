每个技能解决一类具体问题。浏览下方卡片找到需要的技能，进入详情后复制示例提示词发给 agent，替换提示词中的占位符即可开始使用。

10 个技能 4 个分类 复制示例提示词即可使用

电商 · 数据采集

天猫评价采集报告
tmall-review-report
采集天猫店铺出售中商品的用户评价（含图片/追评/商家回复）与问大家问答数据，生成左侧主图导航的交互式 HTML 口碑总览报告（按累计销量降序、标题新标签打开详情页），并自动校验商品主图链接是否 404、过滤运费/补差/滤网/配件等非实物商品。全程浏览器模拟人工点击、不调后端接口，附带商品销售数据（价格/库存/累计销量/30日销量）。当用户提到采集天猫评论/评价、问大家、天猫商品口碑报告、重新生成商品总览、检查商品链接或主图是否有效时使用。
天猫价格核对
tmall-price-checker
采集天猫/淘宝商品 SKU 价格数据（名称/原价/实付价/库存/图片），支持商家后台出售中列表（本店全店首选）/已打开标签页/列表页/URL 列表四种输入。下游输出 Excel（多 sheet 单工作簿、内嵌图片）/ CSV，核心能力是同店跨链接价格一致性核对（同一真实 SKU 复用到多个链接时排查漏改价）。当用户要求采集天猫商品价格、整理 SKU 价格表、核对各链接价格一致性、排查漏改价时使用。
京东评论采集分析
jd-review-collector
采集京东商品页（item.jd.com）带图/视频买家评论并做口碑分析：下载评论原图与视频、逐条情感分类与关键词提炼，产出固定风格的交互式 HTML 报告（情感/评分/SKU/关键词/含视频多维筛选、图片灯箱、视频播放、唯一ID可复制）。当用户给出京东商品链接或提到"采集京东评论/评价""评论分析""买家秀下载""竞品口碑"时使用。内置反人机验证策略（默认50条、慢速翻页、逐页本地回传）。

电商 · 经营报表

天猫销售仓库对账
tmall-sales-to-warehouse-reconciliation
清洗天猫订单商家编码、按指定订单号分离补单，以物流信息和退款状态统计真实订单的 SKU 出库、退货和净销量，生成全量订单、真实订单、补单订单、退货订单、统计五个工作表，供仓库进销存对账。适用于天猫订单 Excel 整理、补单剔除和仓库销量退货核对。
天猫月度经营报表
tmall-monthly-business-report
生成天猫店铺月度经营报告 Excel：订单拆分为全量/补单/退款/有效四个明细表，按商家编码做销售统计（数量/营业额/均价/成本/利润/毛利率），汇总平台费用与推广费每日明细，按 13 元/单计补单费，最终按财务模型输出全公式化的财报。适用于天猫店铺每月对账、经营分析、利润核算场景。
天猫物流到货时长分析
tmall-logistics-analysis
分析淘宝/天猫真实体验分中的物流到货时长，生成城市、线路、异常订单、晚间揽收和临时剔除情景的公式化Excel报告及优化指引。适用于商家要求分析物流分下降、选择快速物流专线城市、模拟新增揽收班次、剔除指定收货城市与商品ID复算、每月复用物流诊断，或需要导出并美化物流分析报告时。

语雀

语雀表格解析
yuque-sheet
解析语雀表格文档（lakesheet）为结构化数据，并支持多种下游输出：打印高清图片、导出 Excel/CSV、数据分析。当用户给出 yuque.com 表格文档链接并要求解析/读取/导出/打印/转图片/转 Excel/分析/统计时使用。核心能力：浏览器登录态提取 → deflate 解压 → SpreadJS 解析。
语雀 MCP 操作
yuque-mcp
通过 yuque MCP 服务器操作语雀（知识库、目录分组、文档、小记、搜索）。当用户提到语雀、在语雀创建分组/文档、整理知识库目录、读取或搜索语雀内容时使用。包含 MCP 接入配置、目录（TOC）操作标准流程与 429 限流处理办法。优先使用本技能而非浏览器自动化操作语雀。

办公工具

发票整理
invoice-organizer
整理指定目录中的发票，按费用用途、含税金额和销售方核心品牌重命名，删除确认重复项，并在对话中汇报数量与金额。适用于周期性发票归档和财务报销整理。
图片切割器
picture-slicer
图片切割器：把超长图片（如电商详情长图）裁成编号分片。优先按 PSD/PSB 参考线切分，也支持指定高度、指定张数、自定义切分要求，以及无依据时按高宽比严格小于 2 自动近等高切分。切分后自动校验完整性，可输出 PNG/JPG。当用户提到切图/图片分割、详情图切片、按参考线导出切片、长图太长无法一次导出时使用。

图片切割器
picture-slicer
办公工具

图片切割器：把超长图片（如电商详情长图）裁成编号分片。优先按 PSD/PSB 参考线切分，也支持指定高度、指定张数、自定义切分要求，以及无依据时按高宽比严格小于 2 自动近等高切分。切分后自动校验完整性，可输出 PNG/JPG。当用户提到切图/图片分割、详情图切片、按参考线导出切片、长图太长无法一次导出时使用。
