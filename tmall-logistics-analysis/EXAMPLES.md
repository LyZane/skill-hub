# tmall-logistics-analysis 示例提示词

复制下面任一场景的提示词发给 agent，替换 `<尖括号>` 占位符即可使用。如果 agent 没有自动调用本技能，在提示词开头加上「使用 tmall-logistics-analysis 技能：」即可显式指定。

## 场景 1｜月度物流到货时长诊断

> 使用 tmall-logistics-analysis 技能：这是体验分页面导出的物流到货时长明细 <明细.xlsx 路径> 和宝贝销售明细 <销售明细.xlsx 路径>。页面平均到货时长为 <数值> 小时，当前揽收班次为 <时间列表>。请核验考核口径，分析城市和线路贡献，比较晚间揽收方案，生成公式化 Excel 报告和优化指引。

## 场景 2｜评估快速物流专线

> 使用 tmall-logistics-analysis 技能：基于 <物流到货时长明细.xlsx 路径> 和 <宝贝销售明细.xlsx 路径>，分析哪些收货城市或线路开通快速专线更能改善全店到货时长。页面平均值为 <数值> 小时，请按订单贡献和可兑现提速目标测算，不要只按城市平均值排序。

## 场景 3｜临时剔除后复算揽收方案

> 使用 tmall-logistics-analysis 技能：请在正式分析之外增加临时情景，剔除收货地为 <城市> 且商品 ID 为 <商品ID> 的订单，重新计算平均到货时长、当前档位，以及 <候选新增揽收时间列表> 的方案。输入文件为 <物流明细.xlsx 路径> 和 <销售明细.xlsx 路径>，页面平均值为 <数值> 小时。临时剔除不要混入正式改善建议。
