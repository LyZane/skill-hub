# 计分规则与数据口径

官方手册：https://qn.taobao.com/headline/news/10721647

## 核心定义

- 物流到货时长：考核订单从消费者支付到签收的平均时长，不是单纯“揽收至签收”。
- 官方手册列示统计周期为前40天至前11天（T-40～T-11）；以当月产品页面为准。
- 页面“近30天有效订单量”用于判断是否达到出分门槛，不等于物流到货时长分母。
- 异常账号、虚假订单、低价订单、恶意攻击及平台公告规定的特殊订单可能不纳入评分。

## 明细验证

1. 导出“物流到货时长订单明细”，独立计算订单数与算术平均值。
2. 平均值与页面展示值四舍五入一致，才将其作为该考核日的计算样本。
3. 检查未超线路标准的订单也应存在，避免误用异常订单清单。
4. 不用销售报表的确认收货时间反推平台指标：平台可能使用物流签收、有效订单过滤及不同考核窗口。

## 主子订单匹配

- 优先用到货明细订单编号匹配宝贝报表的子订单编号。
- 未匹配的多商品订单，用主订单编号＋商品SKU唯一匹配。
- 每个匹配必须唯一；任何缺失、重复或发货时间为空都要报告，不得静默丢弃。
- 发货城市与快递公司决定订单是否适用本店揽收班次；收货城市用于线路和剔除分析。
