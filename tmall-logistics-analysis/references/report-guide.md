# 报告解读与优化指引

## 分析顺序

1. 核对样本均值与页面展示值。
2. 计算超线路标准订单数及超额总小时。
3. 按城市、线路×快递聚合，优先考虑“超额总小时×可兑现提速”的贡献。
4. 比较异常治理、专线目标和组合方案能否跨档。
5. 有揽收需求时，比较各新增时点的覆盖订单、总节省和兑现敏感性。
6. 将临时剔除放在独立工作表，不与正式方案混算。

## 城市与专线指引

- 城市平均慢但单量小，不一定适合开专线；先看能对全店均值贡献多少小时。
- 只有个别异常件的线路先追查异常原因，不凭单笔慢件开专线。
- 24小时、36小时、48小时均为模拟上限，不是快递承诺。开通前向快递确认揽收、干线、末端派送及价格。
- 组合方案需避免重复计算同一订单的收益。

## 晚间揽收模型

当前班次由 `--pickups` 输入。以商家后台发货时间作为包裹可交接时间：

`单笔节省 = max(原下一班次时间－新增班次后的下一班次时间, 0)`

`模拟到货时长 = 原到货时长－单笔节省`

仅对指定发货城市＋快递公司的订单应用。该模型假设后续干线与签收等幅提前，是同步提前情景：

- 若只提前揽收扫描而干线仍次日发运，实际收益可能为零。
- 推荐时点应比较覆盖单量与总节省，不简单选择最晚时间。
- 试行后记录真实揽收、干线发运和签收，验证兑现比例。

## 临时剔除

`剔除后均值 = (原总时长－剔除订单总时长) ÷ (原订单数－剔除订单数)`

剔除样本若比全店更快，剔除后均值会上升。除明确跨档外，不推断精确的中间分变化。需要复算揽收方案时，从受益订单和总节省中同步排除这些订单，以剩余订单数为分母，并在独立的“临时剔除揽收测算”工作表比较所有候选时点。

## Excel浏览标准

- 使用短表头和足够列宽，避免被动换行与`###`。
- 表头与数据行默认统一居中；长商品名、说明等确需左对齐的文本列可以例外，同列保持一致。
- 长说明集中放置或设置换行与足够行高，不在每行重复同一段解释。
- 摘要优先，明细随后；冻结表头与关键标识列，保留筛选。
- 使用统一字体、轻量分隔线和单一强调色；临时情景使用灰色标签。
- 宽表降低缩放并横向打印，所有工作表隐藏网格线。

## 回复结构

1. 先给可执行结论和数值。
2. 说明样本、口径和是否跨档。
3. 明确假设与不能保证的部分。
4. 链接最终`.xlsx`，不交付重算验证副本。
