# 产品图片大小与留白统一

## 核心原则

- 先生成独立预览页和预览副本，不因生成预览而修改原图。
- 只在用户明确确认执行后替换；严格遵守当次指定的排除型号、图位互换和替换范围。
- 不采用“裁出产品主体再贴到白底”的方式，以免切掉产品边缘或自然阴影。
- 主体识别只用于计算缩放比例与中心位置；实际处理对象是整张图片。

## 标准算法

1. 将图片按 EXIF 方向转正并转为 RGB。
2. 在白底图中以灰度 `< 225` 提取主体边界；白色或浅色产品可在预览后调整阈值，但不能凭感觉直接替换。
3. 默认将主体最长边缩放到画布最长边的 `80%`，等比缩放，不拉伸。
4. 按目标比例缩放整张原图，使用高质量 Lanczos 重采样。
5. 根据主体边界中心计算整图放置位置，使主体居中：
   - 小图放大时，移除的是原图外围区域；
   - 大图缩小时，在整图外围补白；
   - 不单独裁切或重绘产品及阴影。
6. 保持原画布尺寸和文件格式，生成独立预览副本。

## 工作流程

1. 确认产品范围、双图来源、目标占比和排除项；存在跨类别重名时，使用 `类别|型号` 作为唯一键。
2. 生成包含原图与效果图的前后对比页面，标注型号、文件名、原主体占比和整图缩放倍率。
3. 检查产品是否完整、阴影是否自然、双图视觉大小是否一致，并验证所有图片路径和页面渲染。
4. 等用户确认后再替换。替换前逐张校验源图 SHA-256，防止覆盖预览之后发生的变化。
5. 替换前永久备份原图，使用同目录临时文件和原子替换；记录源图、备份、前后哈希和缩放倍率。
6. 排除项必须验证替换前后哈希不变；中途失败时回滚本次已替换图片。
7. 替换后更新使用这些图片的下游产物，并运行项目既有的版式或文件完整性检查。

## 注意

- 预览页中的百分比是主体最长边占画布比例，不代表产品真实物理尺寸。
- 放大不会超过原图信息量的限制；如果预览明显模糊，应提示用户，而不是通过裁切或 AI 重绘掩盖。
- 非白底、背景复杂或主体与背景亮度接近的图片需要单独确认识别结果。
