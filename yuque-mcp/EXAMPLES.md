# yuque-mcp 示例提示词

复制下面任一场景的提示词发给 agent，替换 `<尖括号>` 占位符即可使用。如果 agent 没有自动调用本技能，在提示词开头加上「使用 yuque-mcp 技能：」即可显式指定。令牌等敏感信息不要写进提示词，由 agent 从本机配置复用或单独向你索取。

## 场景 1｜接入语雀 MCP

> 请帮我在当前客户端接入语雀 MCP，接入后验证连通性并列出我的知识库。

## 场景 2｜存文档到知识库（最常用）

> 请把以下内容存进我的语雀知识库 <namespace，如 用户名/知识库slug> 的「<分组名>」分组下，文档标题「<标题>」，完成后把链接给我：
>
> <粘贴内容，或本地文件路径>

## 场景 3｜搜索与阅读

> 请在我的语雀里搜索「<关键词>」，挑出最相关的一篇读出正文，帮我总结要点并附原文链接。
