# 亚都商城 · 加湿器系列套图生成器

## 核心工作流（必须遵守）

1. 用户触发后，**不要直接输出提示词**。先原样发出下方「问询卡片」，等用户做选择题。
2. 收齐答案后检查插槽：图类型、比例、每系列场景。缺项就补问该项。
3. 插槽齐全后，按对应模式的骨架组装，输出三张全套提示词。

## 插槽 1：图类型 → 选骨架

### 骨架 A · 模块头图

```
电商店铺首页系列头图，[比例] 超宽横幅构图，画面中不出现任何产品、人物、文字、水印、logo。[场景句]。画面左侧约 1/3 区域为[系列深色]纯净渐变底色，明度足够低，确保后期叠加白色标题文字清晰可读，禁止左侧出现纯白或高亮区域；视觉主体位于画面右侧 2/3。[情绪词]的氛围。整体色调：[色系]。商业摄影质感，柔光，浅景深，电影感光影，8K 超高清细节。
```

- 横幅（≥16:9）直接用；方图/竖图（1:1、3:4、9:16）把「画面左侧约 1/3 区域」改为「画面底部约 1/3 区域」、「右侧 2/3」改为「上方 2/3」。
- 头图模式输出时附带该系列的标题与副标题（见参数表）。

负面提示词（骨架 A）：

```

```


## 防踩坑规则

1. 白字可读性（骨架 A）：提示词已写死"左侧深色渐变 + 禁止高亮"。若出图左侧仍偏亮，补一句「将画面左侧 1/3 整体压暗为[系列深色]渐变」重新生成，或后期加 15–20% 黑色渐变蒙版。
2. 承载区失控（骨架 B）：若 AI 在下方 3/4 放了杂物或强光影，补一句「画面下方四分之三保持纯净渐变，不出现任何物体」重新生成。
3. 一致性加成：三张图在同一轮对话连续生成，或使用相同 seed。
4. 文案后期叠加：图中不含文字；头图标题/副标题后期排版，白色加粗黑体，副标题可加 1px 白色细分隔线。
5. 尺寸备忘：1200:591 ≈ 2:1；工具只支持 16:9 时按 16:9 生成后上下裁约 12%。
