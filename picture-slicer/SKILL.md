# 图片切割器：按参考线或指定规则切分长图

## 输入与原理

- **参考线来源**：PSD/PSB 文件。参考线保存在图像资源块（资源 ID 1032）中，脚本直接二进制解析，不需要 Photoshop。
- **像素来源**：扁平长图（PNG/JPG）。Pillow 打不开 PSB，psd-tools 对超过 30000 像素的合成图会直接拒绝，所以像素必须用用户在 PS 里导出的整张长图。
- 默认需要 PSD/PSB + 导出长图。若画布 ≤30000 像素且只给了 PSD/PSB，脚本会尝试用 psd-tools 读取合成图（需已安装 psd-tools）。

## 执行前确认

切图前先判断需求是否清楚、输入是否齐全、规则是否冲突。只有存在影响切分结果的疑问时才询问；得到答复前不要执行切图。重点检查：

- 是否提供了正确的长图，以及需要时配套的 PSD/PSB。
- 是否要求忽略参考线，是否指定高度、张数、比例、平台限制或自定义边界。
- 高度与张数是否同时指定且相互冲突；自定义要求是否缺少可执行的尺寸或位置。
- 输出格式和位置未指定时使用下方默认值，无需为此额外询问。

## 切分依据优先级

严格按以下优先级选择一种主规则，不要混用：

1. **参考线**：有 PSD/PSB 参考线且用户未声明忽略时，按参考线切。横向、纵向参考线都有时默认横向；长图与 PSD 尺寸不一致时按比例缩放坐标。此优先级下忽略高度或张数参数。
2. **高度或张数**：没有采用参考线时，若用户指定固定高度，用 `--slice-height N`；若指定张数，用 `--count N` 尽量等高切分。两种参数冲突时先询问。
3. **其他要求**：没有采用参考线、高度或张数时，按用户给出的比例、平台限制、指定位置等要求执行；要求不明确时先询问。
4. **无任何依据**：横向自动近等高切分。采用能满足每片 `高度 / 宽度 < 2`（严格小于，不能等于）的最少张数，再让各片高度尽量相同；有余数时最后一片承担一份余量，所有分片高度最多相差 1 px，且最后一片同样必须满足比例限制。无参数调用脚本即可使用此规则。
5. **明确忽略参考线**：使用 `--ignore-guides`，不要参考 PSD/PSB 参考线。没有其他切分要求时等同于无任何依据，走第 4 条；同时给出高度、张数或其他要求时仍按上述优先级执行。

## 运行与校验

```bash
python3 scripts/slice_by_guides.py --psd <PSD/PSB路径> --image <长图路径> --out <输出目录>
```

可选参数：

- `--slice-height N`：按固定高度切。
- `--count N`：按指定张数近等高切。
- `--ignore-guides`：忽略 PSD/PSB 中的参考线。
- `--axis h|v|auto`：默认 auto；无参考线时默认横向。纵向自定义切分需明确参数。
- `--format jpg --quality 90`：输出 JPG，透明底合成白底。

脚本会重新解码每个分片，核对尺寸及总高度（或宽度），确保无重叠、无遗漏；默认模式还会逐片验证 `高度 / 宽度 < 2`。校验失败时不得报告成功。完成后抽查 1–2 张分片的边界。

## 输出约定

- **“原图”专指用户最初提供的长图路径，不是工作区副本、临时文件或压缩包内路径。**
- 默认最终输出目录固定为 `<用户原始长图所在目录>/<用户原始长图名（不含扩展名）>/`；只有用户明确指定其他输出位置时才可更改。
- 若运行环境要求复制输入到工作区，工作副本只用于读取和临时切片。校验通过后必须把分片复制到最终输出目录，并在该目录核对数量、命名和尺寸；不得把工作副本目录当作原图目录。
- 分片命名为 `01.png`、`02.png`…，不带原图名；JPG 输出时扩展名相应为 `.jpg`。
- 保留原图透明通道（PNG）；转 JPG 时透明区合成白底。
- 交付最终输出目录。压缩包只能作为额外交付物，不能替代默认目录中的分片。
