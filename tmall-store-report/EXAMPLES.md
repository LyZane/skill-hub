# tmall-store-report 示例提示词

复制下面任一场景的提示词发给 agent，替换 `<尖括号>` 占位符即可使用。如果 agent 没有自动调用本技能，在提示词开头加上「使用 tmall-store-report 技能：」即可显式指定。采集依赖浏览器中已登录的天猫卖家后台会话。

## 场景 1｜全量采集 → 商品总览（最常用）

> 我的浏览器已登录天猫卖家后台。请采集本店出售中商品的销售数据、用户评价和问大家问答，生成交互式 HTML 商品总览。

## 场景 2｜已有采集数据 → 重新生成总览

> 这个目录里有之前采集好的店铺数据：<tmall_data目录路径>。请重新生成商品总览 HTML。
