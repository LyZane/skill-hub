# 按 PSD/PSB 参考线切分详情长图

## 输入与原理

- **参考线来源**：PSD/PSB 文件。参考线保存在文件的图像资源块（资源 ID 1032），脚本直接二进制解析，不需要 Photoshop。
- **像素来源**：扁平长图（PNG/JPG）。Pillow 打不开 PSB，psd-tools 对超过 30000 像素的合成图会直接拒绝，所以像素必须用用户在 PS 里导出的整张长图。
- 因此默认要两个文件：PSD/PSB + 导出长图。若画布 ≤30000 像素且只给了 PSD/PSB，脚本会自动尝试用 psd-tools 读合成图（需已安装 psd-tools）。

## 工作流

1. 确认输入路径：PSD/PSB（参考线）与长图（像素）；缺长图且画布超 3 万像素时，请用户在 PS 里导出一张整图。
2. 运行切片脚本（仅依赖 Pillow）：

```bash
python3 scripts/slice_by_guides.py --psd <PSD/PSB路径> --image <长图路径> --out <输出目录>
```

可选参数：`--format jpg --quality 90`（JPG 时透明底合成白底）；`--axis h|v|auto`（默认 auto，按有参考线的方向切）；`--slice-height N`（文件里没有参考线时的等分兜底）。

3. 脚本内置校验：每个分片重新解码、尺寸核对、高度（宽度）合计等于原图、无重叠无遗漏；失败以非零退出。校验不通过不得向用户报告成功。
4. 抽查 1–2 张分片目视确认边界落在版面自然分界处（用 Read 看图）。
5. 用 qwenwork_file_present_files 把分片交付给用户。

## 输出约定

- 默认输出到长图同目录下的 `切片/` 子目录，可用 `--out` 覆盖。
- 命名：`<长图文件名>_01.png`、`_02`… 两位补零，从 01 开始。
- 保留原图透明通道（PNG）；转 JPG 时透明区合成白底。

## 常见问题

- **解析到 0 条参考线**：文件可能没存参考线。让用户在 PS 里确认，或改用 `--slice-height N` 等分。
- **长图与 PSD 尺寸不一致**（如导出时缩放过）：脚本按两轴比例自动缩放参考线坐标并打印提示。
- **平台只收 JPG / 限制单张大小**：用 `--format jpg --quality N` 重切一版。
