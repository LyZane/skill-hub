# ecom-sku-collector 示例提示词

复制下面任一场景的提示词发给 agent，替换 `<尖括号>` 占位符即可使用。如果 agent 没有自动调用本技能，在提示词开头加上「使用 ecom-sku-collector 技能：」即可显式指定。采集依赖浏览器中已登录的平台会话，店铺身份以当前登录的浏览器为准，无需填写店铺名。

## 场景 1｜已打开的标签页 → Excel 价格表（最常用）

> 我浏览器已登录天猫，并打开了几个商品详情页。请把当前打开的天猫/淘宝商品标签页里的 SKU 全部采集下来，整理成带内嵌图片的 Excel 工作簿。
