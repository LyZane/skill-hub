# 订单明细获取（千牛「已卖出的宝贝」导出）

一键脚本：`scripts/export_order_report.sh [N=7 | 起始日期 结束日期] [--no-import]`
权威 SOP：`docs/09-订单明细自动导出SOP.md`（含完整踩坑时间线）

## 极限时点与圈单口径

- 最新可拉到**今天盘中**。拉最新时结束日期显式写今天：
  `scripts/export_order_report.sh 2026-10-28 2026-11-03`
  （日历禁选未来日期时脚本自动退回今天 23:59:59 口径；upsert 幂等，次日例行导出会整日覆盖补全）
- 不传日期默认过去 7 天（结束=昨天），日终收尾口径。
- 两条路径圈单字段不同（页面能力决定）：**近3个月路径按「付款时间」，3个月前历史路径按「创建时间」**。
  脚本按起始日期自动选路径；窗口跨 3 个月边界会拒绝并提示拆两段。

## 页面操作关键点（手工兜底 / 排查时用）

入口：`https://qn.taobao.com/home.htm/trade-platform/tp/sold`

**路径 A（近 3 个月）**：确认「近3个月」标签 → 筛选「付款时间」= 起始 ~ **结束日的下一天**
（时分秒保持默认 00:00:00）→ 批量导出 → 选「宝贝销售明细报表」→ 生成报表 → 「请您注意」
隐私弹窗点「确认」→ 记录页等「处理完成」→ 下载。

**路径 B（3 个月前）**：点「3个月前」标签 → 筛选「创建时间」同上 → **必须点「搜索订单」
让筛选生效** → 导出/下载历史订单 → 弹窗自动带入时间 → 生成报表 → 确认 → 下载。
历史路径不点「搜索订单」时，弹窗日期显示「--」且点不动——不是控件坏了，是页面筛选没生效。

## 半开区间边界（最重要的一个坑，2026-10-30 定案）

结束日期选「窗口结束日的**下一天**」、时分秒保持 00:00:00——半开区间天然完整覆盖结束日
全天。若停在结束日 00:00:00，等于把结束日当天**全天静默排除**（10-29 实测漏掉 27 单，
靠支付宝对账才发现）。仅当日历禁选未来日期（当日拉取）才退回 23:59:59。

## 脚本内置的自动校验（不要绕过）

1. **干跑校验**：用 `app/connectors/order_import.py` 解析器本地校验行数/订单数/日期范围。
2. **覆盖校验**：文件里最新订单日期 ≥ 窗口结束日，否则说明结束边界又设错了。
3. **对账校验**（`app/services/recon.py`）：支付宝「消费者体验提升计划服务费」（付款当天按单
   扣、memo 带订单号）核对窗口内每个扣费单号都在订单表。注意两点口径：
   - memo 单号：合并单是主订单号、单一子单订单是子订单号——必须同时匹配 `orders.tid` ∪
     `order_items.oid`，只对子单号会把合并单误报成漏单；
   - 该费并非每单都扣（10 月约 355/454），对账是**下界探测**：报出的一定真缺，没报不能证明无缺。
4. 任一不过 → 自动重试整个浏览器导出**一次**（重试提示词会强调结束日期）；重试后仍早于
   结束日只提示不报错（淡季当天可能确实无付款订单）。

## 导入语义

- 端点 `POST /settings/import/orders`；upsert 按 tid/oid 幂等，同文件重复导入不重复累计；
  导入文件留存 `data/imports/orders/` 供追溯。
- 导出时尽量勾选：**商家编码、宝贝属性（规格）、退款状态**（成本核算依赖）。
- 列名别名与状态映射：`app/connectors/order_import.py` 的 ALIASES；文件列名变化导致校验
  失败时，手动上传一次看报错，按 `docs/06` 校准。

## 故障排查速查

| 现象 | 处置 |
|------|------|
| 对账报「N 笔扣费单号不在订单表」 | 先查 `sync_runs` 有无本次 `import_orders`（导入静默失败会伪装成缺单）；确认落库后，到千牛按单号搜：搜得到=导出未覆盖（渠道单），搜不到=刷单扣费可忽略 |
| 历史弹窗日期「--」 | 没点「搜索订单」；关弹窗→点搜索→重导出 |
| 报表一直「生成中」 | 单量大时正常（4795 单也在数分钟内完成）；到 `.../tp/export-list` 手动下载 |
| 「✓ 已下载」后导入回执是空行 | 导入静默失败，见 pitfalls.md #4（端口被占 501） |
| 想看浏览器每步截图 | `cat ~/.openclaw-autoclaw/sessions/<session_id>/task_result.md` |
| 划词悬浮层（Kimi 等扩展）挡按钮 | 按 Escape 关闭；频繁出现临时禁用该扩展 |
