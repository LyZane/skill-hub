# 推广消耗获取（阿里妈妈万相台无界版导出）

一键脚本：`scripts/export_promo_report.sh [N=30 | 起始日期 结束日期] [--no-import]`
权威 SOP：`docs/07-推广消耗自动导出SOP.md`

## 极限时点（重要：别白跑）

- 最新**只能拉到昨天**——阿里妈妈口径当天消耗未结算完整。
- 且**昨日数据次日上午才生成**：凌晨跑只拿到前天。脚本遇明细无数据会等 30 秒重查、仍无则
  报「平台数据未生成」、**拒绝下载空报表**——这是护栏不是故障，上午再跑即可，别反复重试。
- 万相台无对账单类开放 API；TOP 侧 universalbp API 已封装（`app/connectors/alimama_report.py`）
  但需软件著作权，暂缓。

## 页面操作要点（手工兜底用）

报表页 URL 由脚本按日期拼好（`one.alimama.com` 报表页 + startTime/endTime）。「营销场景报表」
区域：营销场景**全选**（8 个）、数据汇总周期（日常用「过去 N 天」预设；自定义单日区间日历
易卡，仅用于补历史缺口）、时间粒度**分日**、报表模板**全部计划**。「营销场景数据明细」区域：
维度**全选**（下拉只有 全选/时间/营销场景 三项，没有「权限」——旧记录有误）。

然后「下载报表」→ 弹窗默认（全部数据指标）→ 确定 → 生成后下载；弹窗消失太快没点到，去
下载任务管理页 `https://one.alimama.com/index.html#!/report/download-list` 勾最新任务下载。

## 三个已固化的护栏（任务提示词里都有，手工时必须保留）

1. **严禁下载旧任务**：复用的标签页若停在「下载任务管理」页，浏览器任务会直接把列表里
   已有的旧任务（甚至是空报表）再下一遍、根本不去生成新报表。必须先导航回报表页。
2. **明细无数据不下载**：先确认明细表格有数据行再点下载（见上「极限时点」）。
3. 复用 `one.alimama.com` 已有标签页（session pool），没有才新开。

## 产物与导入语义

- 产物 `~/Downloads/营销场景报表_YYYYMMDD_HHMMSS.zip`，内为 **GBK 编码 CSV**（71 列）；
  `promo_import.read_table` 原生处理 zip + GBK。
- 导入取「日期 + 花费」两列；场景级明细按日求和为账户日消耗，场景名存 raw。
- **同日覆盖语义**：同一天以本次文件内的合计为准覆盖、不重复累计；但新文件若只含部分
  场景会覆盖掉之前多场景合计（当前账户仅「货品全站推广」在投，无此风险）。
- 端点 `POST /settings/import/promo`。

## 故障排查速查

| 现象 | 处置 |
|------|------|
| 报表 zip 仅表头、解析 0 条 | 平台未出该日数据（凌晨常见），上午重跑 |
| 下载到旧报表 | 标签页停在下载任务管理页；重跑脚本（护栏会先导航回报表页） |
| 导出正常但无导入回执 | 端口 8000 被非本系统进程占用 → 导入静默 501，见 pitfalls.md #4；确认 Server 头是 uvicorn 后 `curl -F "file=@报表.zip" http://127.0.0.1:8000/settings/import/promo` 补导 |
