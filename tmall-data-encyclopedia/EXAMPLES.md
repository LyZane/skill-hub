# tmall-data-encyclopedia 示例提示词

复制下面任一场景的提示词发给 agent，替换 `<尖括号>` 占位符即可使用。如果 agent 没有自动调用本技能，在提示词开头加上「使用 tmall-data-encyclopedia 技能：」即可显式指定。

> 本技能配套经营看板系统使用，命令均需在看板仓库根目录执行；操作商家后台依赖带登录态的 Chrome 浏览器通道。

## 场景 1｜补数据（全源补齐）

> 使用 tmall-data-encyclopedia 技能：帮我补数据，把看板里所有落后的数据源补到各自能达到的最新时点，补完核对水位并汇报每源覆盖到哪天。

## 场景 2｜拉订单并核对缺单

> 使用 tmall-data-encyclopedia 技能：导出 <开始日期> 到 <结束日期> 的订单明细并导入，跑完付款扣费对账；如果有单号不在订单表，先确认导入真的落库了，再逐单核查是缺单还是异常单扣费。

## 场景 3｜补推广消耗

> 使用 tmall-data-encyclopedia 技能：万相台推广数据还没导，帮我拉过去 <N> 天的消耗报表并导入；如果平台还没出昨日数据就告诉我什么时点再跑，不要反复重试。

## 场景 4｜查数据字典

> 使用 tmall-data-encyclopedia 技能：我要分析 <分析主题，如：各商家编码的退款原因分布>，帮我从数据目录查这些数据分别在哪个表/哪个源、有哪些字段、最新到哪天，能本地查的就不要去平台拉。

## 场景 5｜排查处数异常

> 使用 tmall-data-encyclopedia 技能：<现象描述，如：订单脚本显示已下载但没有导入回执 / 对账报 N 笔扣费不在订单表 / 推广报表是空的>，帮我按踩坑总账排查根因并处置。

## 场景 6｜研究直连快路

> 使用 tmall-data-encyclopedia 技能：<数据源名称> 目前走浏览器导出太慢，帮我研究能不能用接口直连或页面 XHR 拿数，可行就实现，结论（含死路）记入数据目录的直连研究台账。
